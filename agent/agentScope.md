# 安装

**要求：JDK17+**
## 依赖选择
|方式|适用场景|特点|
|---|---|---|
|**all-in-one**|快速开始、大多数用户|单一依赖，默认带 DashScope SDK|
|**core + 扩展**|精细控制依赖|按需引入，依赖最小化|
## All-in-One（推荐）

Maven：
```
<dependency>
    <groupId>io.agentscope</groupId>
    <artifactId>agentscope</artifactId>
    <version>1.0.12</version>
</dependency>
```
