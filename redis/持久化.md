
Redis 持久化通常有两种方式：RDB 和 AOF

# 1.RDB 快照

RDB 会在指定时间点，把 Redis 内存中的数据生成一个二进制快照文件：

```
dump.rdb
```

 例如配置：
```
save 900 1
save 300 10
save 60 10000
```

含义：

```
save 900 1
save 300 10
save 60 10000
```


也可以手动执行：

```
save
```

save会阻塞 Redis 主线程，一般不建议在线上使用。

bgsave 会创建子进程，在后台生成 RDB 文件，通常使用这种方式

## 优点：

- 文件体积小
- 数据恢复速度快
- 对 Redis 正常读写性能影响较小
